# TMC Processor v1.0.1 — preparation

This patch is prepared for review; it is not tagged or published.

Peak Hour is evaluated only in fixed whole-hour intervals (for example
08:00–09:00). Survey data remains at 15-minute resolution; each Peak Hour
contains four intervals. AM/PM search windows bound the whole-hour candidates.

Single and Batch Analyze no longer offer rolling mode. Calculation,
confirmation and export boundaries reject incompatible Peak intervals.
No Peak is rounded or coerced to fit a native template.

Legacy rolling sessions retain project metadata, directions, Mapping, PCE
and search windows. Their Peak decisions and existing analysis/export are
discarded, with a warning requiring Analyze, Review and explicit confirmation
again. Valid fixed-hour session round trips remain supported.

Raw normalization, PCE/PCU, PHF, Mapping, search-window semantics, template
formulas/layout, and Standard/Safe PNG calculations are unchanged.

Issue #23 is no longer applicable to the clarified product contract. Keep it
open until merge/release acceptance; the proposed closure rationale is in the
maintenance evidence package. Published v1.0.0 assets and release tags remain
unchanged.
