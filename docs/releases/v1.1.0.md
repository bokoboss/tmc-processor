## Highlights

- Native V2 Summary support in the existing Excel template, with 24 worksheets and two charts in the accepted synthetic demo workbook.
- V2 Summary rounds PCU once after aggregation. The accepted demo totals are F30=2,981, F31=3,153 and F32/W40/AM22=23,959; the precise total is 23,959.041 PCU.
- The supplied Support QR is included in the Windows ZIP. Opening Support preserves the current workflow state.
- The separate Demo ZIP contains synthetic files for trying the workflow without real survey data.

## Known limitations

- Issue [#42](https://github.com/bokoboss/tmc-processor/issues/42) remains open. For the synthetic demo, the V1 Summary displays F32=23,956 PCU while supporting total cells W40/AM22 display 23,959. V2 Summary has the accepted round-once totals above. The V1 calculation and template have not been changed to address this discrepancy.
- Batch Project Session remains unsupported because the current session format does not round-trip Batch uploads and Batch Mapping Presets.
- Issue #40 tracked an Excel GUI opening rejection for a Cloud workbook. That report was not reproducible in the later current-M365 acceptance, and the V2 Cloud workbook was accepted. The original cause was not established; this is not a claim that a fix was identified or that all Excel versions are compatible.
- Automated package checks do not establish Excel GUI chart recalculation behavior across Excel versions.

## Protected behavior

Calculation, Mapping, QC, Peak semantics, V1 export, and existing Excel template,
drawing, and chart behavior remain protected. This release adds the V2 Summary
capability and its round-once PCU presentation without changing the V1 formulas.
