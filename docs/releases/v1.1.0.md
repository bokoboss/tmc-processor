# TMC Processor v1.1.0 — release preparation

This release note is a preparation draft for Issue #36. It does not mean v1.1.0
has been merged, tagged, deployed, or published. Release publication remains
gated on pull request review, all required CI, post-merge validation, and
separate approval.

## Included work

- Align package, runtime, report metadata, and release bundle labels at version
  `1.1.0`.
- Include the supplied Support QR image in the Windows runtime bundle without
  changing its source bytes.
- Carry forward the hosted Streamlit readiness and Support view from Issue #30.
- Carry forward the accepted native V2 Summary export from Issue #32.
- Carry forward the accepted round-once V2 Summary PCU totals from Issue #34.
- Prepare separate Windows runtime and synthetic Demo-Files ZIP assets.

## Behavior and qualification

This is release hardening and packaging. Calculation, Mapping, QC, Peak,
V1/V2 export logic, Excel templates, drawings, and charts remain unchanged.
The accepted hosted deployment is [tmc-process.streamlit.app](https://tmc-process.streamlit.app/);
the v1.1.0 version banner and post-merge Cloud behavior still require verification
after the approved merge.

## Known limitations

- Excel COM GUI recalculation is not independently observable in the current
  automated release checks; the qualified OOXML and workbook package checks do
  not claim a GUI recalculation result.
- Batch Project Session remains unsupported because the current session format
  does not round-trip Batch uploads and Batch Mapping Presets.
